# Projeto_Integrador_VENUO
O projeto Venuo consiste na criação da arquitetura técnica e no desenvolvimento de um protótipo digital interativo de uma plataforma de geolocalização voltada para lazer. A proposta é desenvolver uma solução que reúna, em uma única interface interativa, informações sobre bares, restaurantes e eventos na Região Metropolitana de Goiânia.
